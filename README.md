# 조사 자료 그래프

동식물상 조사 **종합 데이터 팩(Excel)** 을 불러와 시트마다 표와 그래프로 보여 주는 정적 사이트입니다.

- 주소: https://report.biogrideia.com/
- 엑셀은 브라우저 안에서만 읽습니다(서버로 보내지 않음). 마지막으로 불러온 파일은 그 브라우저에만 남아 다음에 열면 바로 보입니다.
- 새 주소는 호스팅케이알 DNS의 CNAME 레코드(`report` → `cirmax82-beep.github.io`)로 연결됩니다.

## 쓰는 법

1. **엑셀 불러오기** 또는 파일을 화면에 끌어다 놓기
2. 왼쪽에서 시트 고르기 — 1차·2차 시트는 탭으로, **차수 비교** 탭은 두 차수를 한 그래프로
3. 그래프마다 종류(세로·가로 막대, 누적, 100% 누적, 원, 도넛, 꺾은선, 표만)·계열·정렬·상위 N개·행·열 바꾸기·제목을 바꿈
4. 위쪽 막대에서 그래프 너비·높이·글자 크기, 표 글자 크기, 그림 배율, 색(색각 친화·Okabe-Ito·회색조), 무늬(흑백 인쇄용)를 조절
5. 받기: 그래프는 PNG·SVG·CSV, 표는 CSV·표 복사(한글·워드에 붙여넣기)

조사가 바뀌면 새 데이터 팩을 다시 불러오면 바로 다시 그립니다. 고른 그래프 종류·항목은 그대로 남습니다.
크롬·엣지에서 **엑셀 불러오기**로 연 파일은 **다시 읽기** 버튼과 **저장하면 자동 반영**(엑셀에서 저장하면 몇 초 안에 다시 그림)을 쓸 수 있습니다.

## 시트 인식

시트 이름의 번호와 `_1차`·`_2차`를 떼고 남은 이름으로 그래프 구성을 고릅니다(`js/views.js`).
모르는 시트도 숫자 열이 있으면 일반 막대·원 그래프와 표로 보여 줍니다.

| 시트 | 그래프 |
|---|---|
| 총괄 및 통계 | 분류군별 과·속·종 수, 현지·문헌 종수, 출현종 구성(원), 법정보호종·교란종·고유종, 식물 특이종 |
| 식물상 마스터 | 과(속·대분류·생활형)별 종수, 대분류·생활형별 종수, 현지·문헌 겹침, 특이 식물, 비고 표시별 |
| 동물상 마스터 | 분류군별 종수, 현지·문헌 겹침, 분류군별 목(과·강)별 종수, 조류 도래유형, 법정보호종·교란·고유종, 현지 개체수(숫자 기록) |
| 법정보호종 / 특이종 목록 | 분류군별 등급(구분)별 종수, 확인 출처(현지·문헌N)별 종수 |
| 문헌마스터 / 문헌별 출현 현황 | 분류군별 문헌 수, 문헌별 분류군 수 / 분류군·문헌별 종수·과수·법정보호종 수 |
| 생활형 분석 | 구성비 비교(현지·남한·한반도·Raunkiaer), 출현종수, 남한 대비 차이 |
| 지점별 우점 / 물환경 평가 | 지점별 우점·아우점종 개체수 / TESB·AESB, 환경상태 등 지점 수 |
| 관속식물 집계표 | 문별 과·속·종 수, 분류 계급별 구성 |
| 그 밖의 분석 시트 | 숫자 열 그대로(목별·과별·도래유형·종별 우점 등) |

## 파일

- `index.html`, `css/style.css`
- `js/parse.js` 엑셀 → 시트·표 블록, `js/views.js` 시트별 그래프 구성, `js/chart.js` 그래프 카드, `js/table.js` 표, `js/app.js` 화면
- 라이브러리: SheetJS(엑셀 읽기), Apache ECharts(그래프) — CDN
- 고친 뒤에는 `index.html`의 `?v=` 숫자를 올려야 방문자 브라우저가 새 파일을 받습니다.
